# Decisions

Deviations from `docs/banana-build-spec.md` and library choices, newest last.

| Date | Area | Decision | Why |
| --- | --- | --- | --- |
| 2026-10-11 | Repo | One GitHub repo (`GoBanana`) with `banana-server/` and `banana-plugin/` folders instead of two repos. | Owner started in a single repo. Folders match the spec names so they can split out later without moves inside each folder. |
| 2026-10-11 | MCP | `mcp-handler` 2.x renamed `createMcpHandler` to `createMcpRouteHandler` and now builds on `@modelcontextprotocol/server` 2.x (split SDK). Spec example uses the 1.x names. | Follow current library docs (spec rule 4). |
| 2026-10-11 | Tooling | TypeScript pinned to 5.9.3, not 7.x. | Next.js 16 type plugin and many tools still target the 5.x compiler API. |
| 2026-10-11 | Milestones | M1 infra code is written, but its "Done when" (live deploy + AuthKit login) needs owner credentials. Pure library work from M2 to M4 (bend engine, sources, layout, palette math, exports) was built in parallel because it has no dependency on M1 infra. | Unblocks progress while credentials are pending. Nothing is wired to production until M1 is verified. |
| 2026-10-11 | Sources | `web_search` image host rule: if Serper's `imageUrl` host is not allowlisted but its `thumbnailUrl` host is (Google thumbnails), keep the result and use the thumbnail URL as both image and thumb. If only the image host is allowlisted, the image URL is used as the thumb too. Drop only when neither host is allowlisted. | Spec section 8 says drop when the image host is not allowlisted. Pinterest pins often point at the original blog image, which would drop most results. Every URL we return is still on the allowlist, so the inline canvas CSP holds. |
| 2026-10-11 | Sources | `SourceQuery` gained an optional `sources` field, and the web_search adapter exposes `run()` returning `{ references, note, ok }` next to the spec's `search()`. | Spec signature has no way to pass selected sites or the "fewer results with a note" message. `ok` lets the tool count quota only when Serper answered. |
| 2026-10-11 | Sources | Results whose source page is not on a selected site are dropped; caller-typed `site:` operators are stripped from queries. Serper `num` is 2x count rounded up to 10, capped at 50. Takedown list load failure fails closed (no results, plain note). | Keeps results to the chosen sites and the Serper bill bounded; never shows results we could not check. |
| 2026-10-11 | Quota | Searches are counted only when Serper answers 200. Paid plans at the search cap get a reset date message, not an upgrade link. Item cap is all or nothing per `add_to_canvas` batch. | Users should not pay quota for our outages; paid users have nothing to upgrade to. |
| 2026-10-11 | Palette | Decoders: `jpeg-js` (typed-array mode, no Node `Buffer`) and `upng-js` (with `pako`), both pure JS, in memory. Quantizer: own deterministic median cut over a fixed sampling grid (20k samples total, alpha < 128 skipped), then merge clusters closer than 0.06 in OKLab and drop clusters under 1% of samples. `node-vibrant` not used. | Spec section 4 asks to record the choice. Pure JS runs on Workers without wasm setup; the merge and noise floor stop JPEG noise and edge blends from becoming fake swatches. |
| 2026-10-11 | Palette | WebP (and GIF) return `unsupported_format` and are listed in `skipped`. Recommended later: `@jsquash/webp` (libwebp in wasm, ESM, documented for Cloudflare Workers by importing the `.wasm` module and passing it to `init()`). Not installed. | Keeps v1 dependency free of wasm bundling; WebP thumbnails are skipped with a plain note instead of failing the call. |
| 2026-10-11 | Palette | `extractPalette` returns up to `size` colors, fewer when the images hold fewer distinct colors (no made-up tints). Roles are filled in order surface, on-surface, primary, accent, neutral, secondary; extras (size 7 to 9) get `neutral` or `secondary`. Output adds `skipped: [{ index, format, reason }]`. OKLCH strings use 3, 3 and 1 decimals; hex stays the source of truth. | Spec does not say what to do for flat images or sizes other than 6; inventing colors would misreport the references. |
| 2026-10-11 | Palette | `fetchThumbIntoMemory(url, { allowedHosts, fetchImpl?, maxBytes = 2 MB, timeoutMs = 8 s })`: https only, allowlist checked on every redirect hop (max 3, `redirect: "manual"`), image content type required, returns a result object and never throws or logs. | Spec gives no signature; a redirect must not escape the allowlist. |
| 2026-10-11 | Layout | Layout coordinates are absolute. by_direction: section frames have a 48 px title band and 16 px bottom padding; items with no known section go in a last column with no frame. grid: square cells, up to 4 per row. hero: first item is a 2x2 cell block (2 cells plus a gap), the rest in rows of up to 4 cells centered below it. Cell and column size default 280 px, gap 16 px for all layouts. | Spec section 9 gives only one line per layout; "ring below" read as centered rows under the hero. |
