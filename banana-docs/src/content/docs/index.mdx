## How a run goes

<Flow
	steps={[
		{ title: 'Pin', body: 'Platform and one to three pages. Ask the whole product, and the agent asks where the weirdness should go.' },
		{ title: 'Bend', body: '8 ideas, each with a visual spec. The agent drops the ones that cannot become UI and keeps 3 or 4.' },
		{ title: 'Search', body: 'Two zones per direction: art direction images and real UI for your platform. Junk is rated out.' },
		{ title: 'Board', body: 'Art row above a UI grid, a "steal:" note on every tile, the source link on every image.' },
		{ title: 'Frankenstein', body: 'Cut parts from the UI references and stack new page variants. Optional.' },
		{ title: 'Hand off', body: 'DIRECTION.md, BUILD-PROMPT.md, rules for Cursor, Copilot, Claude Code and Codex. Then build and critique.' },
	]}

<Aside type="tip" title="Not your design system">
GoBanana is for one crazy idea over a page or two: a launch page, onboarding, an empty state, a 404, a paywall, a year in review. Your product keeps its own design system. Every exported file applies only to the pages you name and inherits your system.
</Aside>
