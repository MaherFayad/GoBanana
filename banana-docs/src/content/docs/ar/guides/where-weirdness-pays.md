title: أين يؤتي الجنون ثماره
description: الصفحات التي تستحق فيها فكرة جامحة واحدة مكانها، لكل منصة، والصفحات التي يجب أن تبقى هادئة.
---

يؤتي الجنون ثماره حيث يصل الناس ولديهم وقت وفضول، أو حيث تستحق اللحظة أن تبقى في الذاكرة. ويكلفك حيث يحاول الناس إنجاز مهمة بسرعة.

عندما تطلب من GoBanana المنتج كله، تعمل `bend_brief` دون صفحات وتعيد `wildSpots`: أفضل 5 مواضع لمنصتك. يعرضها الوكيل ويسأل **«أين تريد الجنون؟»**. اختر من 1 إلى 3.

## الهاتف

| الموضع | لماذا يؤتي ثماره |
| --- | --- |
| التعريف بالتطبيق | يرى مرة واحدة، ويحدد النبرة، ولم يتعلم أحد التخطيط بعد |
| الحالة الفارغة | لا شيء يقرأ بعد، فالشاشة تتسع لفكرة قوية |
| لحظة إنجاز أو سلسلة أيام | المكافأة يجب أن تبدو مميزة، لا كأي شاشة أخرى |
| شاشة الاشتراك | شاشة اشتراك لا تنسى تبيع الإحساس، لا قائمة الميزات فقط |
| شاشة البداية | ثانية من الهوية دون مهمة تعترضها |
| حصاد العام | مصنوع للمشاركة، فيجب ألا يشبه أي شيء آخر |
| حالة الخطأ أو انقطاع الاتصال | خطأ مفاجئ يحول لحظة سيئة إلى ابتسامة |
| مفاجأة مخفية في الإعدادات | ركن مخفي يكافئ الفضوليين دون أن يعرض المسار الرئيسي للخطر |
| شاشة النجاح | المهمة انتهت، فالبهجة لا تكلف شيئا |

**أبقها هادئة:** تسجيل الدخول، خطوات الدفع، النماذج، القوائم التي يتصفحها الناس يوميا، شريط التبويب.

**أبقها هادئة:** أدوات العرض المقسوم، المحررات، إدخال البيانات.

## الموقع

| الموضع | لماذا يؤتي ثماره |
| --- | --- |
| صفحة الإطلاق | لها مهمة واحدة، أن تبقى في الذاكرة، وتعيش لأسابيع |
| صفحة الحملة | عمرها قصير، فيمكنها كسر أسلوب العلامة بأمان |
| صفحة 404 | لا أحد يتوقعها، فالفكرة الجريئة تصيب دون تكلفة |
| صفحة من نحن أو البيان | صفحات القصة هي المكان الذي ترحب فيه الشخصية |
| صفحة الأسعار | صفحات الأسعار كلها متشابهة، والتميز يبني الثقة إذا بقيت الخطط سهلة المقارنة |
| التذييل | من يمرر حتى هناك فضولي، فكافئه |
| صفحة الوظائف | الثقافة تظهر في شكل الصفحة أكثر مما تقوله |
| سجل التغييرات | يقرؤه المعجبون، والشكل الجديد يجعل التحديثات تبدو أكبر |
| صفحة فعالية أو مؤتمر | مصنوعة لإثارة الاهتمام في لحظة واحدة |

**أبقها هادئة:** صفحات التوثيق، الدفع، نماذج التسجيل، الصفحات القانونية.

| الحالات الفارغة | الجداول الفارغة مساحة ميتة، وفكرة فيها تعلم وتبهج |
| التشغيل الأول | الدقائق الخمس الأولى تحدد شعور الناس تجاه الأداة |
| صفحة 404 | لا أحد يتوقعها، فالفكرة الجريئة تصيب دون تكلفة |
| سجل التغييرات | يقرؤه المعجبون، والشكل الجديد يجعل التحديثات تبدو أكبر |

| حالات التحميل | الانتظار ممل، وفكرة صغيرة تجعله يبدو أقصر |
| الاحتفال بمرحلة مهمة | أدوات العمل نادرا ما تحتفل، فيبرز ذلك |
| صفحة تسجيل الدخول | تُرى كل يوم، ولا بيانات فيها تحتاج حمايتها من الزخرفة |

**أبقها هادئة:** الجداول، المحررات، التنقل، وكل ما يستخدمه الناس لساعات.

## قواعد عامة

- **اختر من 1 إلى 3 مواضع.** أكثر من ذلك يصبح الاتجاه الرئيسي للمنتج، وليس هذا ما صمم GoBanana له.
- **الأجزاء الهادئة تبقى على نظام التصميم الخاص بك.** الصفحة الجامحة ترثه ولا تغير منه إلا ما تحتاجه الفكرة.
- **الصفحة الجامحة تجتاز WCAG 2.2 AA مع ذلك** وتحترم إعداد تقليل الحركة. حتى في مستوى Bananas، تحافظ ملفات التسليم على تباين النص وأحجام أهداف اللمس.

يعرض الخادم أول 5 مواضع من كل قائمة أعلاه. وتعرض المهارة من 4 إلى 6.
