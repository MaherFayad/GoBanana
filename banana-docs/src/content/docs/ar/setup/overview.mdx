GoBanana خادم MCP بعيد. كل التطبيقات تتصل بالعنوان نفسه:

<ServerUrl />

- **طريقة النقل:** Streamable HTTP. لا عملية محلية تثبتها ولا شيء تشغله.
- **تسجيل الدخول:** OAuth 2.1 عبر WorkOS AuthKit. يفتح تطبيقك نافذة متصفح في المرة الأولى. لا مفتاح API تلصقه.
- **الحساب:** أول تسجيل دخول ينشئ حسابك في GoBanana. استخدم البريد نفسه على الويب لترى لوحاتك في `/ar/canvases`.
- **الإضافة (Claude فقط):** تضيف إضافة Claude تسع مهارات فوق الخادم. التطبيقات الأخرى تحصل على الأدوات دون المهارات.

## الإعدادات جنبا إلى جنب

<Tabs syncKey="client">
<TabItem label="Claude Code">

```bash
# With the skills (recommended), Claude Code 2.1.275 or later; then /mcp to sign in
/plugin install gobanana --marketplace MaherFayad/GoBanana

# Older versions
/plugin marketplace add MaherFayad/GoBanana
/plugin install gobanana@gobanana

# Server only, no skills
claude mcp add --transport http gobanana https://gobanana-server.maherfayad55.workers.dev/api/mcp
```

## ثم تحقق

اطلب من وكيلك: **«تحقق من اتصالي بـ GoBanana.»** سيستدعي `ping` ويجب أن يرد بـ:

```text
Connected to GoBanana as you@example.com.
```

مزيد من الفحوص: [تحقق من أنه يعمل](/docs/ar/setup/check/). إذا كان هناك خلل: [حل المشكلات](/docs/ar/setup/troubleshooting/).

## أي تطبيق أستخدم؟

| التطبيق | المهارات | اللوحة داخل المحادثة | يكتب الملفات في مستودعك |
| --- | --- | --- | --- |
| Claude Code | نعم، مع الإضافة | لا، رابط ويب | نعم |
| Claude.ai وClaude Desktop | نعم، مع الإضافة (Cowork وإضافات المؤسسات) | نعم (MCP Apps) | لا، انسخها من الرد |
| ChatGPT | لا | لم تختبر | لا |
| Cursor وVS Code وWindsurf وCodex | لا | لم تختبر، استخدم رابط الويب | نعم |

أفضل تركيبة اليوم: استكشف وركب صفحات فرانكنشتاين في Claude.ai أو Claude Desktop حيث تظهر اللوحة داخل المحادثة، ثم سلم من Claude Code أو Cursor أو Codex داخل مستودعك، بالحساب نفسه.

للوحة دائما رابط ويب، فيستطيع كل تطبيق فتحها، داخل المحادثة أو خارجها.
