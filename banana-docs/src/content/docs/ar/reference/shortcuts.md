---
title: اختصارات لوحة المفاتيح
description: كل اختصارات اللوحة، من القائمة نفسها التي تستخدمها اللوحة.
---

اضغط <kbd>?</kbd> في اللوحة لفتح هذه القائمة هناك. يعني <kbd>Mod</kbd> المفتاح <kbd>Cmd</kbd> على Mac، والمفتاح <kbd>Ctrl</kbd> في غيره.

كل سحب في اللوحة له طريق بلوحة المفاتيح أيضا.

## في أي مكان في اللوحة

| المفاتيح | الإجراء |
| --- | --- |
| <kbd>?</kbd> | عرض اختصارات لوحة المفاتيح |
| <kbd>Shift</kbd> <kbd>1</kbd> | ملاءمة العرض |
| <kbd>Shift</kbd> <kbd>2</kbd> | التكبير على التحديد |
| <kbd>Mod</kbd> <kbd>A</kbd> | تحديد كل العناصر |
| <kbd>Esc</kbd> | إلغاء التحديد (يغلق القائمة أولا) |
| <kbd>Mod</kbd> <kbd>D</kbd> | تكرار التحديد |
| <kbd>H</kbd> | أداة اليد: اسحب للتنقل |
| <kbd>V</kbd> | أداة التحديد: اسحب للتحديد |

## على اللوحة

| المفاتيح | الإجراء |
| --- | --- |
| <kbd>+</kbd> | تكبير |
| <kbd>-</kbd> | تصغير |
| <kbd>Mod</kbd> <kbd>0</kbd> | التكبير إلى 100% |
| مفاتيح الأسهم | تحريك العرض |
| <kbd>Shift</kbd> مع مفاتيح الأسهم | تحريك العرض مسافة أكبر |
| اضغط مع الاستمرار على <kbd>Space</kbd> واسحب | التنقل أثناء الضغط |
| عجلة الفأرة | التنقل (مع <kbd>Shift</kbd> للتنقل الأفقي) |
| <kbd>Mod</kbd> مع عجلة الفأرة | التكبير باتجاه المؤشر |
| السحب على مساحة فارغة | تحديد منطقة |

## على عنصر محدد

| المفاتيح | الإجراء |
| --- | --- |
| مفاتيح الأسهم | تحريك العنصر 8 بكسل |
| <kbd>Shift</kbd> مع مفاتيح الأسهم | تحريك العنصر 32 بكسل |
| <kbd>+</kbd> | تكبير العنصر |
| <kbd>-</kbd> | تصغير العنصر |
| <kbd>M</kbd> أو <kbd>Shift</kbd> <kbd>F10</kbd> | فتح قائمة العنصر (نقل إلى قسم، تقديم للأمام، حذف) |
| <kbd>F2</kbd> | تعديل ملاحظة أو عنوان أو دور |
| <kbd>Space</kbd> | معاينة صورة |
| <kbd>Delete</kbd> أو <kbd>Backspace</kbd> | حذف العنصر |
| <kbd>Shift</kbd> مع النقر | إضافة إلى التحديد أو إخراج منه |
| <kbd>Alt</kbd> مع السحب | سحب نسخة |
| <kbd>Mod</kbd> مع السحب | التحريك دون محاذاة |

## في نتائج البحث

| المفاتيح | الإجراء |
| --- | --- |
| <kbd>Enter</kbd> | إضافة النتيجة إلى اللوحة |
