title: اختصارات لوحة المفاتيح
description: كل اختصارات اللوحة، من السجل نفسه الذي تستخدمه اللوحة (canvas/shortcuts.ts). اضغط ? على اللوحة لتراها هناك.
---

**Mod** هو مفتاح Command على Mac ومفتاح Control على Windows وLinux. لكل إيماءة بالمؤشر طريق بديل عبر لوحة المفاتيح (WCAG 2.2 SC 2.5.7).

## في أي مكان على اللوحة

| المفاتيح | الوظيفة |
| --- | --- |
| `?` | عرض اختصارات لوحة المفاتيح |
| `Shift` `1` | تكبير لملاءمة كل المحتوى |
| `Shift` `2` | تكبير إلى العناصر المحددة |
| `Mod` `A` | تحديد كل العناصر |
| `Escape` | إلغاء التحديد (يغلق القائمة أولا إن كانت مفتوحة) |
| `Mod` `D` | تكرار العناصر المحددة |
| `H` | أداة اليد: اسحب لتحريك العرض |
| `V` | أداة التحديد: اسحب للتحديد |

## على اللوحة (عندما يكون التركيز على اللوحة)

| المفاتيح | الوظيفة |
| --- | --- |
| `+` | تكبير |
| `-` | تصغير |
| `Mod` `0` | تكبير إلى 100% |
| مفاتيح الأسهم | تحريك العرض |
| `Shift` + مفاتيح الأسهم | تحريك العرض مسافة أكبر |
| `Space` + سحب | تحريك العرض أثناء الضغط |
| عجلة الفأرة | تحريك العرض (`Shift` للتحريك أفقيا) |
| `Mod` + عجلة الفأرة | تكبير نحو المؤشر |
| السحب على مساحة فارغة | تحديد منطقة |

## على عنصر عليه التركيز

| المفاتيح | الوظيفة |
| --- | --- |
| مفاتيح الأسهم | تحريك العنصر 8px |
| `Shift` + مفاتيح الأسهم | تحريك العنصر 32px |
| `+` | تكبير العنصر (32px) |
| `-` | تصغير العنصر (32px) |
| `M` أو `Shift` `F10` | فتح قائمة العنصر: المعاينة، والملاحظة، وعلامة **Ship** أو **Explore**، و**Cut part** (قص جزء)، وفتح المصدر، والنقل إلى قسم، والتكرار، والإحضار للأمام، والإزالة |
| `F2` | تعديل ملاحظة أو عنوان أو دور |
| `Space` | معاينة صورة |
| `Delete` أو `Backspace` | إزالة العنصر |
| `Shift` + نقر | إضافة إلى التحديد أو إخراج منه |
| `Alt` + سحب | سحب نسخة |
| `Mod` + سحب | تحريك بلا محاذاة تلقائية |

## في نتائج البحث (الدرج)

| المفاتيح | الوظيفة |
| --- | --- |
| `Enter` | إضافة النتيجة التي عليها التركيز إلى اللوحة |
| مفاتيح الأسهم على علامات التبويب | التبديل بين **UI** (الواجهات) و**Art direction** (الاتجاه الفني) و**Parts** (الأجزاء) |
| `Space` في تبويب **Parts** | اختيار جزء لصفحة فرانكنشتاين جديدة |

## في صفحة فرانكنشتاين

| المفاتيح | الوظيفة |
| --- | --- |
| مفاتيح الأسهم | نقل التركيز بين الخانات |
| `Alt` + مفاتيح الأسهم | تحريك الخانة التي عليها التركيز |
| `Home`، `End` | الخانة الأولى أو الأخيرة |
| `Enter` | إعادة قص الخانة (**Recrop**) |
| `M` أو `Shift` `F10` | قائمة الخانة: إعادة القص، والاستبدال بجزء، والملاحظة، والتحريك، والضم إلى صف، وصف مستقل، وفتح المصدر، والإزالة |
| `F2` | تعديل ملاحظة الخانة (وعلى الإطار: إعادة التسمية) |
| `Delete` أو `Backspace` | إزالة الخانة من الصفحة |
| `Escape` | العودة إلى الإطار |
| مفاتيح الأسهم على مبدّل العرض | **Collage** و**Wireframe** و**Even** |

## النوافذ ومربعات الحوار

`Escape` يغلق القوائم والمعاينة ومحرر القص. ويعود التركيز إلى العنصر الذي بدأت منه.
