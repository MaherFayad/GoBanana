يرتب اللوحة أو قسما واحدا منها. استخدمه بعد إضافة العناصر، أو عندما تريد لوحة أنظف.

**الاسم في العملاء:** Arrange canvas

## المعاملات

<div class="gb-table">

| المعامل | النوع | إلزامي | الوظيفة |
| --- | --- | --- | --- |
| `canvasId` | نص | نعم | معرف اللوحة. |
| `layout` | نص | نعم | `by_direction` (عمود لكل قسم) أو `masonry` (4 أعمدة مع الحفاظ على شكل الصور) أو `grid` (خلايا متساوية) أو `hero` (العنصر الأول كبير والباقي أسفله). |
| `sectionId` | نص | لا | يرتب هذا القسم فقط. |

</div>

## مثال

```json
{
  "canvasId": "<canvasId>",
  "layout": "masonry"
}
```

## ما تعيده

كل عنصر مع موضعه وحجمه الجديدين، ورابط الويب.

## الخطة

مجانية.
