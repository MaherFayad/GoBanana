يقرأ اللوحة: وصفها واتجاهاتها وأقسامها وعناصرها مع روابط مصادرها وملاحظاتها، وعينات الألوان ولوحات الألوان. اترك `canvasId` لعرض لوحاتك الأخيرة، ليضيف الوكيل إلى إحداها بدل إنشاء لوحة جديدة.

**الاسم في العملاء:** Get canvas

## المعاملات

<div class="gb-table">

| المعامل | النوع | إلزامي | الوظيفة |
| --- | --- | --- | --- |
| `canvasId` | نص | لا | اللوحة المراد قراءتها. اتركه لعرض آخر 10 لوحات. |

</div>

## مثال

```json
{
  "canvasId": "<canvasId>"
}
```

## ما تعيده

اللوحة وقائمة نتائجها، أو قائمة باللوحات الأخيرة، الأحدث أولا.

## الخطة

مجانية. للقراءة فقط.
