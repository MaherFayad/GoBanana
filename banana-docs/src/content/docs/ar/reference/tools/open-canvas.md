يعرض لوحة داخل المحادثة، أو ينشئ لوحة ويعرضها إذا لم تمرر `canvasId`، ويعيد رابطها على الويب. العملاء الذين يدعمون MCP Apps يعرضون اللوحة في المحادثة، وكل العملاء يحصلون على رابط الويب.

**الاسم في العملاء:** Open canvas

## المعاملات

<div class="gb-table">

| المعامل | النوع | إلزامي | الوظيفة |
| --- | --- | --- | --- |
| `canvasId` | نص | لا | اللوحة المراد فتحها. اتركه لإنشاء لوحة جديدة. |
| `title` | نص | لا | عنوان اللوحة، حتى 80 حرفا. |
| `brief` | نص | لا | وصف التصميم، حتى 500 حرف. |
| `taste` | قائمة | لا | حتى 5 كلمات قصيرة تصف الأسلوب، كل منها حتى 40 حرفا، مثل `["glassmorphism", "big typography", "dark mode"]`. تحفظ على اللوحة لعمليات البحث اللاحقة. |

</div>

## مثال

```json
{
  "canvasId": "<canvasId>"
}
```

## ما تعيده

`id` و`title` و`webUrl` و`brief` للوحة، مع عدد العناصر والأقسام والنتائج في قائمة النتائج.

## الخطة

الفتح مجاني. إنشاء لوحة يحسب من حد اللوحات: 3 في المجانية، وبلا حد في Pro.
