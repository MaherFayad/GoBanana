---
title: Where weirdness pays off
description: The pages where one wild idea earns its keep, per platform, and the pages to keep calm.
---

Weirdness pays where people arrive with time and curiosity, or where a moment deserves to be remembered. It costs where people are trying to get a task done fast.

When you ask GoBanana for a whole product, `bend_brief` runs without pages and returns `wildSpots`: the top 5 spots for your platform. The agent shows them and asks **"Where should the weirdness go?"** Pick 1 to 3.

## Mobile

| Spot | Why it pays |
| --- | --- |
| Onboarding | Seen once, sets the tone, and nobody has learned the layout yet |
| Empty state | Nothing to read yet, so the screen has room for a strong idea |
| Achievement or streak moment | A reward should feel special, not like every other screen |
| Paywall | A memorable paywall sells the feeling, not just the feature list |
| Splash screen | A second of brand with no task to get in the way |
| Year in review | Made to be shared, so it should look like nothing else |
| Error or offline state | A surprising error turns a bad moment into a smile |
| Settings easter egg | A hidden corner rewards the curious without risking the main flow |
| Success screen | The task is done, so delight costs nothing |

**Keep calm:** sign in, checkout steps, forms, lists people scan daily, the tab bar.

## Tablet

| Spot | Why it pays |
| --- | --- |
| Onboarding | Seen once, and the big canvas gives the idea room |
| Empty state | A large blank area is the best place for one bold image |
| Reading or focus mode | Long sessions reward a distinct, calm world |
| Achievement moment | A reward should feel special on the big screen |
| Paywall | A memorable paywall sells the feeling, not just the features |
| Splash screen | A moment of brand with no task in the way |
| Year in review | Made to be shared, so it should look like nothing else |

**Keep calm:** split view tools, editors, data entry.

## Website

| Spot | Why it pays |
| --- | --- |
| Launch page | It has one job, to be remembered, and it lives for weeks |
| Campaign page | Short lived, so it can break the house style safely |
| 404 page | Nobody expects it, so a bold idea lands for free |
| About or manifesto page | Story pages are where personality is welcome |
| Pricing page | Everyone's pricing looks the same; standing out builds trust, if plans stay easy to compare |
| Footer | People who scroll that far are curious, so reward them |
| Careers page | Culture shows best in how a page looks, not what it says |
| Changelog | Fans read it, and a fresh look makes updates feel bigger |
| Event or conference page | Built to create buzz for one moment |

**Keep calm:** docs, checkout, sign up forms, legal pages.

## Web app

| Spot | Why it pays |
| --- | --- |
| Empty states | Blank tables are dead space; an idea there teaches and delights |
| First run | The first five minutes set how people feel about the tool |
| 404 page | Nobody expects it, so a bold idea lands for free |
| Changelog | Fans read it, and a fresh look makes updates feel bigger |
| Upgrade modal | A memorable upgrade moment sells better than a plain list |
| Loading states | Waiting is boring; a small idea makes it feel shorter |
| Milestone celebration | Work tools rarely celebrate, so it stands out |
| Login page | Seen every day, with no data to protect from decoration |

**Keep calm:** tables, editors, navigation, anything people use for hours.

## Rules of thumb

- **Pick 1 to 3 spots.** More than that and it becomes the product's main direction, which is not what GoBanana is for.
- **The calm parts stay on your design system.** The wild page inherits it and overrides only what the idea needs.
- **A wild page still passes WCAG 2.2 AA** and respects reduced motion. Even at Bananas, the hand-off files keep text contrast and target sizes.

The server shows the first 5 spots of each list above. The skill shows 4 to 6.
