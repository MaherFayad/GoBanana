title: Share links and uploads
description: Give someone a view-only link to a canvas, and add your own images.
---

Share links and uploads are part of Pro. During the beta, every signed-in account has Pro limits. See [Plans and limits](/docs/reference/plans/).

## Share a canvas

1. Open the canvas on the web.
2. Choose **Share** in the toolbar.
3. Choose **Create view link**.
4. Choose **Copy link**.

Anyone with this link can view the canvas. They cannot change it. The link is not listed or shown in search engines.

The shared page shows every reference with its source link, like the canvas does.

### Change or stop a link

- **Make a new link.** The old link stops working.
- **Turn off link.** The link stops working, and the canvas is private again.

Your [canvases page](https://gobanana-server.maherfayad55.workers.dev/en/canvases) shows which canvases have a view link on.

## Upload your own images

Choose **Upload image** in the canvas toolbar.

| Rule | Value |
| --- | --- |
| File types | PNG, JPEG, WebP, GIF |
| Size per file | 10 MB |
| Storage per account | 1 GB |

GoBanana checks the real file type from the file itself, so a file with the wrong extension is refused. It only takes files you send. It never fetches an image from a link.

Uploads belong to your account. Deleting your account removes them.

:::note
On Free, the **Upload image** and **Share** controls show a note with a link to the plans.
:::
