[Mobbin](https://mobbin.com) is a library of real, shipped app and web screens. It answers "how do the best apps do checkout today?". GoBanana answers "what could checkout look like that nobody has shipped?". Seeing both side by side keeps a wild idea honest.

## How it works

If you have **your own Mobbin connector** in your client, the agent checks for it **first**, before it bends anything, and uses both: Mobbin for what shipped apps do on your page, GoBanana for the directions that go past it. This works with the plugin (`gobanana-explore`) and with the GoBanana connector alone: the server's instructions tell any agent to do it. GoBanana's server never calls Mobbin.

<Steps>

1. **Check.** The agent looks for tools named like `search_screens`, `search_flows` or `search_sections` from a Mobbin connector. None found: it skips every Mobbin step silently.
2. **Baseline, before the bend.** It searches **once per page**, the same page on the same platform ("checkout" on iOS), and reads 3 to 6 shipped screens: the layout most apps share (the default to escape) and the patterns users rely on (the must keeps).
3. **Pick better directions.** It drops ideas that only restyle the baseline and keeps ideas that change the page while keeping the must keeps.
4. **Anchor each direction.** For each kept direction it picks 2 to 4 Mobbin screens that fit: the real pattern the idea builds on, or a shipped screen that is already wild in its way. It places them in that direction's UI references grid, each with a `steal:` note, and adds `BUILD ON: [Revolut, payment sheet](mobbin link)` to the direction's idea note.
5. **One baseline note** on the board: `Shipped today: [Airbnb, checkout](mobbin link), [Revolut, payment sheet](mobbin link), ...`, with a few of its screens beside it when the board has room, and one line in the reply.
6. **Parts for Frankenstein pages.** A Mobbin screen on the board can be cut into a part like any UI reference. The agent uses one when it is wild or fits the direction, for example a real pay bar under a wild hero, never as the whole page.

</Steps>

## The rules

- **Shown from Mobbin, never copied.** A Mobbin screen on the board is the image link your connector returned, loaded by your browser straight from Mobbin. GoBanana never downloads, stores or re-hosts it, and the server never fetches it.
- **Always linked.** Each screen's source chip reads mobbin.com and opens the screen's page on Mobbin. Every export and share link keeps that link.
- **Only what the agent places.** GoBanana's server never searches Mobbin. It keeps the two links the agent passes (the screen page and the image, both on mobbin.com) and refuses links from anywhere else. Mobbin links are never passed to `search_references`.
- **Image links expire.** Mobbin's image links stop working after about 30 days. The tile then shows a card with the title and a link to the screen on Mobbin. Ask the agent to place it again to get a fresh image.
- **Your account, your terms.** The agent uses your Mobbin connector under your Mobbin plan and terms.

<Aside type="note" title="Connecting Mobbin">
How to add a Mobbin connector depends on Mobbin and your client; GoBanana does not set it up. In Claude, look for Mobbin under Settings, Connectors.
</Aside>

## Without a connector

Open Mobbin in a browser next to your GoBanana board. Copy links to the shipped screens you want as a baseline and ask the agent to "add a Shipped today note with these links". Without the connector there is no image link, so these stay links in a note.
