[Mobbin](https://mobbin.com) is a library of real, shipped app and web screens. It answers "how do the best apps do checkout today?". GoBanana answers "what could checkout look like that nobody has shipped?". Seeing both side by side keeps a wild idea honest.

## How it works

If you have **your own Mobbin connector** in your client, the agent checks for it **first**, before it bends anything, and uses both: Mobbin for what shipped apps do on your page, GoBanana for the directions that go past it. This works with the plugin (`gobanana-explore`) and with the GoBanana connector alone: the server's instructions tell any agent to do it. GoBanana's server never calls Mobbin.

<Steps>

1. **Check.** The agent looks for tools named like `search_screens`, `search_flows` or `search_sections` from a Mobbin connector. None found: it skips every Mobbin step silently.
2. **Baseline, before the bend.** It searches **once per page**, the same page on the same platform ("checkout" on iOS), and reads 3 to 6 shipped screens: the layout most apps share (the default to escape) and the patterns users rely on (the must keeps).
3. **Pick better directions.** It drops ideas that only restyle the baseline and keeps ideas that change the page while keeping the must keeps.
4. **Anchor each direction.** For each kept direction it finds 1 or 2 Mobbin screens or sections with the real pattern the idea builds on, and adds `BUILD ON: [Revolut, payment sheet](mobbin link)` to that direction's idea note.
5. **One baseline note** on the board: `Shipped today: [Airbnb, checkout](mobbin link), [Revolut, payment sheet](mobbin link), ...`, and one line in the reply.

</Steps>

## The rules

- **Links only.** Mobbin screens are never placed as images, never downloaded, never saved.
- **Never sent to GoBanana.** Mobbin links are not passed to `search_references` or placed as references. The only trace on GoBanana's side is the text of your board note.
- **Your account, your terms.** The agent uses your Mobbin connector under your Mobbin plan and terms.

<Aside type="note" title="Connecting Mobbin">
How to add a Mobbin connector depends on Mobbin and your client; GoBanana does not set it up. In Claude, look for Mobbin under Settings, Connectors.
</Aside>

## Without a connector

Open Mobbin in a browser next to your GoBanana board. Copy links to the shipped screens you want as a baseline and ask the agent to "add a Shipped today note with these links".
