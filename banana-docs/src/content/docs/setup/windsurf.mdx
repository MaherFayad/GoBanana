Windsurf was renamed **Devin Desktop** in 2026. Its Cascade panel still reads remote MCP servers from an `mcp_config.json` file.

<Steps>

1. In the Cascade panel, click the **...** (Actions) menu at the top right, go to the **MCPs** section and click **Open MCP config file**. Opening it from the app avoids guessing the path, which depends on your version:
   - Devin Desktop (per its docs): `~/.config/devin/mcp_config.json` on macOS and Linux, `%APPDATA%\devin\mcp_config.json` on Windows.
   - Older Windsurf builds: `~/.codeium/windsurf/mcp_config.json` (`%USERPROFILE%\.codeium\windsurf\mcp_config.json` on Windows).

2. Add GoBanana under `mcpServers` and save:

   ```json title="mcp_config.json"
   {
     "mcpServers": {
       "gobanana": {
         "serverUrl": "https://gobanana-server.maherfayad55.workers.dev/api/mcp"
       }
     }
   }
   ```

   The docs accept `serverUrl` or `url` for a remote server.

3. Back in the **MCPs** section, make sure the toggle next to **gobanana** is on. When it asks you to sign in, your browser opens the GoBanana sign in page.

4. In Cascade, ask: **"Use the GoBanana ping tool."**

</Steps>

<Aside type="note" title="100 tools">
Cascade can use 100 tools in total at a time, across all servers. GoBanana has 17 for the agent. If some are missing, turn off tools you do not need in other servers.
</Aside>

Windsurf does not load Claude plugins. Paste the playbook from [No plugin?](/docs/start/first-board/#no-plugin), or save it as a rule. For hand-off, BUILD-PROMPT.md and the AGENTS.md section work here. See [Hand off](/docs/guides/handoff/).

## What was verified

Checked on 2026-10-12 against the Cascade MCP docs (now at docs.devin.ai), which give the menu path, the `serverUrl` field, the 100 tool limit, and say OAuth is supported but do not describe the sign in screens. The older Windsurf path comes from current third party guides, not an official page. Windsurf is not installed on this machine, so nothing here was run. If your build cannot sign in to remote servers, use the bridge in [Other MCP clients](/docs/setup/other-clients/#stdio-only-clients).
