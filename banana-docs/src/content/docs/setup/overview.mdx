GoBanana is a remote MCP server. Every client connects to the same address:

<ServerUrl />

- **Transport:** Streamable HTTP. There is no local process to install and nothing to run.
- **Sign in:** OAuth 2.1 through WorkOS AuthKit. Your client opens a browser window the first time. There is no API key to paste.
- **Account:** your first sign in creates your GoBanana account. Use the same email on the web to see your boards at `/en/canvases`.
- **Plugin (Claude only):** the Claude plugin adds 9 skills on top of the server. Other clients get the tools without the skills.

## The config, side by side

<Tabs syncKey="client">
<TabItem label="Claude Code">

```bash
# With the skills (recommended), Claude Code 2.1.275 or later; then /mcp to sign in
/plugin install gobanana --marketplace MaherFayad/GoBanana

# Older versions
/plugin marketplace add MaherFayad/GoBanana
/plugin install gobanana@gobanana

# Server only, no skills
claude mcp add --transport http gobanana https://gobanana-server.maherfayad55.workers.dev/api/mcp
```

</TabItem>
<TabItem label="Claude apps">

**Customize**, then **Connectors**, then **Add custom connector**. URL:

```text
https://gobanana-server.maherfayad55.workers.dev/api/mcp
```

</TabItem>

## Then check it

Ask your agent: **"Check my GoBanana connection."** It calls `ping` and should answer:

```text
Connected to GoBanana as you@example.com.
```

More checks: [Check it works](/docs/setup/check/). Something off: [Troubleshooting](/docs/setup/troubleshooting/).

## Which client should I use?

| Client | Skills | Inline canvas | Writes files to your repo |
| --- | --- | --- | --- |
| Claude Code | Yes, with the plugin | No, web link | Yes |
| Claude.ai, Claude Desktop | Yes, with the plugin (Cowork and organization plugins) | Yes (MCP Apps) | No, copy from the reply |
| ChatGPT | No | Not tested | No |
| Cursor, VS Code, Windsurf, Codex | No | Not tested, use the web link | Yes |

The best pairing today: explore and Frankenstein in Claude.ai or Claude Desktop where the board shows inline, then hand off from Claude Code, Cursor or Codex in your repo, using the same account.

The board always has a web link, so every client can open it, inline or not.
