Claude.ai (web), Claude Desktop and Cowork share one list of connectors. Add GoBanana once and it works in all of them. Custom connectors work on the Free, Pro, Max, Team and Enterprise plans; the Free plan allows one custom connector.

This is the best place to **explore**: Claude shows the GoBanana canvas inline in the chat (MCP Apps), so you see the board without leaving the conversation.

## Add the connector

<Tabs syncKey="claude-plan">
<TabItem label="Free, Pro, Max">

<Steps>

1. Go to **Customize**, then **Connectors**.

2. Click **Add custom connector**.

3. For **MCP server URL**, enter `https://gobanana-server.maherfayad55.workers.dev/api/mcp`. Give it the name `GoBanana` if the dialog asks.

4. Authentication, if the dialog asks:
   - **Authentication:** **Sign in now** (or **Sign in when needed**).
   - **OAuth client:** **Use Claude's published identity** (recommended) or **Register automatically**. GoBanana's sign in service supports both. Do not enter a client ID or secret.

5. Click **Add**, then **Connect**. A window opens on the GoBanana sign in page. Sign in; the connector shows as connected.

</Steps>

</TabItem>
<TabItem label="Team, Enterprise">

An Owner adds GoBanana for the organization once:

<Steps>

1. Go to **Organization settings**, then **Connectors**.
2. Select **Add**, then **Custom**. If asked for the type, choose **Web**.
3. Enter the server URL and click **Add**. Leave the OAuth client ID and secret empty.

</Steps>

Then each member connects with their own account: **Customize**, **Connectors**, find **GoBanana** with the **Custom** label, click **Connect** and sign in.

</TabItem>
</Tabs>

## Turn it on in a chat

Click the **+** button in the message box, select **Connectors**, and make sure **GoBanana** is on. Then ask: **"Check my GoBanana connection."** Claude calls `ping` and replies with your email.

## Add the skills

The connector gives Claude the tools. The skills give it the playbook (pin the page, bend 8, keep 3, audit, two zones, steal notes). To get them:

- **The plugin (recommended, paid plans):** one install adds the skills and the connector. In the Claude app or on claude.ai, open **Customize**, then **Plugins**, choose **Add**, then **Add marketplace**, then **Add from a repository**, and enter `MaherFayad/GoBanana`. Then add **GoBanana** from the list and sign in when Claude asks. No GitHub? Download [gobanana-plugin.zip](https://gobanana-server.maherfayad55.workers.dev/downloads/gobanana-plugin.zip) and choose **Add**, then **Upload plugin**. The site's **Add to Claude** button shows the same steps. Plugins you add for your claude.ai account also sync to Cowork and Claude Code.
- **Organizations:** an admin may limit which marketplaces and plugins you can add.
- **Without the plugin:** paste the short playbook from [No plugin?](/docs/start/first-board/#no-plugin) at the start of a chat, or save it in a Claude Project's instructions.

## The inline canvas

When the agent calls `open_canvas`, Claude renders the GoBanana board inside the chat. You can pan, zoom, move tiles, edit notes and use the keyboard shortcuts; changes save to the same board you see on the web. While it is open, the inline board refreshes on its own when the agent adds to it (about every 4 seconds while it has focus).

**Upload** and **Share** need a web session, so they show on the full screen board at `/c/<id>` only. Uploaded images show as link cards inline.

## Allow tool calls

Claude asks before tool calls. Choose **Always allow** only for GoBanana's read and rate tools. Under **Customize**, **Connectors**, select GoBanana to set each tool's permission; keep `delete_canvas` on asking, or set it to **Blocked** if you never want chat to delete boards.

## Limits of the apps

Claude.ai and Claude Desktop cannot write files into your repo. When you ask for a hand-off, Claude shows each file with its path; copy them, or run the hand-off from [Claude Code](/docs/setup/claude-code/), [Cursor](/docs/setup/cursor/) or [Codex](/docs/setup/codex/) with the same account.
