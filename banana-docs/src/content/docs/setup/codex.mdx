import { Aside, Steps, Tabs, TabItem } from '@astrojs/starlight/components';

Codex reads `AGENTS.md`, so it picks up GoBanana's scoped AGENTS.md section on its own after a hand-off.

<Steps>

1. Add the server. Pick one:

   <Tabs syncKey="codex">
   <TabItem label="Command">

   ```bash
   codex mcp add gobanana --url https://gobanana-server.maherfayad55.workers.dev/api/mcp
   ```

   Codex detects that the server uses OAuth and starts the sign in right away.

   </TabItem>
   <TabItem label="config.toml">

   Add this to `~/.codex/config.toml`:

   ```toml title="~/.codex/config.toml"
   [mcp_servers.gobanana]
   url = "https://gobanana-server.maherfayad55.workers.dev/api/mcp"
   ```

   </TabItem>
   </Tabs>

2. Log in, if it did not start on its own:

   ```bash
   codex mcp login gobanana
   ```

   A browser opens on the GoBanana sign in page. On a machine with no browser, add `--no-browser` and paste the callback URL when asked.

3. Check the server is listed:

   ```bash
   codex mcp list
   ```

4. Start Codex and ask: **"Use the GoBanana ping tool."**

</Steps>

The Codex IDE extension and the Codex app read the same `config.toml`, so one setup covers all three.

## Without skills

Codex does not load Claude plugins. Paste the playbook from [No plugin?](/docs/start/first-board/#no-plugin), or put it in your `AGENTS.md` outside the GoBanana markers.

## Hand off for Codex

Ask "hand this off". The agent exports `agents_md` (Pro) and merges one section into `AGENTS.md` between `<!-- gobanana:<slug> -->` markers, never touching the rest. On Free, use BUILD-PROMPT.md. See [Hand off](/docs/guides/handoff/).

<Aside type="note" title="Tokens">
Codex stores the OAuth token in your system keyring or its credentials file. To sign out, run `codex mcp logout gobanana`.
</Aside>
