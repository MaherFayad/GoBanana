# Big type display (`big-type-display`)

Part of the GoBanana style index (docs/styles/INDEX.md). The general skill that reads a style from a
thumbnail is `gobanana-taste` in banana-plugin. Load this file when a direction names `big-type-display`.

## Definition

One word or short line set huge, in a condensed, bold or oversized sans, is the image.

## Visual signals

Check these in the thumbnail. Three or more yes means the reference is this style.

- Letters cropped by the frame or filling it.
- One or two words ("KPI REPORT", "WAKE UP WORLD").
- Tight leading.
- Small grey meta text in a corner.

Genres: Deck, Brand, Web showcase, Mobile.

## Great versus cheap (the owner's bar, docs/taste-bar.md)

- **Great:** One idea, a real typeface with character, a calm margin.
- **Cheap:** A big default sans plus three bullets, mixed display fonts, huge text that wraps badly.

## Do

- Use one display face with character.
- Let the word crop or fill the frame on purpose.
- Keep everything else small and quiet.

## Don't

- No bullets under the big word.
- No two display faces fighting.
- No widows or bad wraps at display size.

## Nearest neighbour: `editorial-serif` (Editorial serif)

Look at the letterform. Big type is a heavy or condensed sans shouting; editorial serif is a refined serif speaking. A huge figure with data meaning is hero numeral.

## Judge rubric

Use it in rate_references, the Bench judge and critique. A reference is rated against the brief's
page first, then against this style.

1. **Is it this style?** Yes when 3 or more signals above show in the thumbnail. If it is closer to
   `editorial-serif`, tag it that way instead.
2. **great:** on the brief's page, could sit on the owner's boards, one focal idea, real content,
   and none of the cheap marks.
3. **good:** on style and on page, but generic.
4. **bad:** off page, off style when the style was asked, or any cheap mark: A big default sans plus three bullets, mixed display fonts, huge text that wraps badly.
5. **Slop flags (J8 default AI look), each lowers the grade one step:** a centred hero over three
   rounded 12 to 29 px cards, a soft indigo or violet gradient, system-ui plus a Georgia accent,
   gradient text.
