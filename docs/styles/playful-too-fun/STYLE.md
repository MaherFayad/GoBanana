# Playful, too fun (`playful-too-fun`)

Part of the GoBanana style index (docs/styles/INDEX.md). The general skill that reads a style from a
thumbnail is `gobanana-taste` in banana-plugin. Load this file when a direction names `playful-too-fun`.

## Definition

Character, colour and bounce first: the page is a toy.

## Visual signals

Check these in the thumbnail. Three or more yes means the reference is this style.

- Big rounded or bubble letters.
- A character or mascot.
- Saturated colour blocks and tilted elements.
- Hand-drawn or toy-like 3D props.

Genres: Web showcase, Brand, Deck, Mobile.

## Great versus cheap (the owner's bar, docs/taste-bar.md)

- **Great:** Joyful and still clear: one idea, tight craft, content still readable.
- **Cheap:** Clip-art mascots, rainbow everything, comic fonts, stock cartoon people.

## Do

- Pick one character or one move and commit.
- Keep the navigation and content plain and readable.
- Respect reduced motion: the fun must work still.

## Don't

- No comic fonts.
- No rainbow palette with no system.
- No stock cartoon people.

## Nearest neighbour: `illustrative-handmade` (Illustrative and handmade)

Look at the feel. Playful is loud and energetic; illustrative handmade can be calm, quiet or literary. A static bold ground with no character is flat colour field.

## Judge rubric

Use it in rate_references, the Bench judge and critique. A reference is rated against the brief's
page first, then against this style.

1. **Is it this style?** Yes when 3 or more signals above show in the thumbnail. If it is closer to
   `illustrative-handmade`, tag it that way instead.
2. **great:** on the brief's page, could sit on the owner's boards, one focal idea, real content,
   and none of the cheap marks.
3. **good:** on style and on page, but generic.
4. **bad:** off page, off style when the style was asked, or any cheap mark: Clip-art mascots, rainbow everything, comic fonts, stock cartoon people.
5. **Slop flags (J8 default AI look), each lowers the grade one step:** a centred hero over three
   rounded 12 to 29 px cards, a soft indigo or violet gradient, system-ui plus a Georgia accent,
   gradient text.
