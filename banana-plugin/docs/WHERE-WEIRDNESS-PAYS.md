# Where weirdness pays

GoBanana is for one crazy idea over a page or two, not the whole product. Weirdness pays where people arrive with time and curiosity, or where a moment deserves to be remembered. It costs where people are trying to get a task done fast.

`bend_brief` returns `wildSpots` for the platform when no `pages` are given. `gobanana-explore` shows them as a picker: "Where should the weirdness go?" This page is the same list with reasons, for when you want to pick yourself.

## Mobile

| Spot | Why it pays |
| --- | --- |
| Splash and first launch | Seen once, sets the tone, no task to slow down |
| Onboarding | People expect a story here; a strong idea helps them remember why they installed |
| Paywall | It has to stand out to convert; a memorable offer beats a generic plan list |
| Empty states | A blank screen with nothing to do is the cheapest place to delight |
| Success and celebration | The task is done, so a bold moment costs nothing |
| Year in review, recap | Made to be shared; it is a poster, not a form |
| Settings easter egg | Found by fans, rewards curiosity |

Keep calm: sign in, checkout steps, forms, lists people scan daily, the tab bar.

## Tablet

| Spot | Why it pays |
| --- | --- |
| Welcome and onboarding | Big canvas, people sit back |
| Reading or lean back views | Long dwell time, room for a layout idea |
| Empty states | Large blank area that begs for an idea |
| Recap and stats stories | Shareable, made to look at |

Keep calm: split view tools, editors, data entry.

## Website

| Spot | Why it pays |
| --- | --- |
| Launch page | Exists to be noticed and shared; one big idea is the job |
| Campaign or drop page | Short lived, so risk is cheap |
| Homepage hero | First 5 seconds; a strong idea earns the scroll |
| 404 page | Nobody planned to be here; a joke or a gift turns a miss into a smile |
| Pricing page | Usually the same 3 cards everywhere; a clear twist stands out, if plans stay easy to compare |
| About and manifesto | Brand voice lives here |
| Year in review, changelog highlight | Made to be shared |

Keep calm: docs, checkout, sign up forms, legal pages.

## Web app

| Spot | Why it pays |
| --- | --- |
| First run and empty dashboard | No data yet, so the screen is free to set the tone |
| Upgrade and paywall moments | Must stand out from the daily UI to be read |
| Success states, milestones | Rare, earned, safe to celebrate |
| Year in review, usage recap | A story, not a table |
| 404 and error pages | A rare miss, a chance to be human |
| Settings easter egg, about dialog | Found by fans |

Keep calm: tables, editors, navigation, anything people use for hours.

## Rules of thumb

- Pick 1 to 3 spots. More than that and it becomes the product's main direction, which is not what GoBanana is for.
- The calm parts of the product stay on the project's design system. The wild page inherits it and overrides only what the idea needs.
- A wild page still passes WCAG 2.2 AA and respects reduced motion.
